🔗 Live Demo

https://sumansuiwal992.github.io/Netflix-Homepage/

📌 About

This is a mobile-friendly Netflix homepage clone featuring a fixed navbar, hero banner, and multiple scrollable content rows, with smooth hover interactions and a dark theme design.

✨ Features

- Fully responsive layout (mobile, tablet, desktop)
- Fixed navbar with scroll-based background change
- Hero banner section with Play and More Info buttons
- Multiple horizontally scrollable content rows (Trending, Popular, Continue Watching, Sci-Fi & Fantasy, Action & Adventure)
- Hover zoom effect on movie/show cards
- Drag-to-scroll support on content rows
- Dark theme UI matching Netflix's design language
- Footer with project disclaimer

🛠️ Built With

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript (ES6+)
- Font Awesome Icons
